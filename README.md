Core Principle

NOVA STORE is a production-oriented marketplace.

The backend and database are the single source of truth.

The interface must never invent products, prices, stock, sellers, orders, reviews, or delivery information.

Development Rules

1. Build the correct system before polishing the UI.
2. Keep authentication, catalog, orders, payments, delivery, finance, messaging, AI, and administration modular.
3. Use API versioning under "/api/v1/".
4. Never hard-code business-critical values.
5. Inventory operations must be transaction-safe.
6. AI recommendations must reference real catalog products.
7. All permissions must be enforced by the backend.
8. Sensitive data must be protected.
9. Production secrets must come from environment variables.
10. Every critical workflow must be testable.
